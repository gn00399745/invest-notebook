# AI 投資筆記

依「AI 投資分析架構」建立的個人投資筆記網站（PWA，可安裝到手機）。

頁面分五組（導覽集中定義在 `nav.js` 的 `NAV`，新增頁面只要改那裡）：
- 💰 資產：資產總覽、收支記帳、交易紀錄
- 🔍 研究：選股雷達、策略組合、個股研究卡、產業定位、ETF 健檢
- 🌐 市場：進出場時機、極端訊號、總經、週期研究、黃金・匯率、監控提醒
- 🎯 計畫：財務計畫、覆盤、待驗主張・回測
- 📚 學習：技術分析教學、投資流程與資料來源、設定與備份

手機：底部五個分頁＋頁面上方的分組切換；電腦（寬 1100px 以上）：左側選單一次列出全部頁面。

- 純靜態網站（HTML/CSS/JS），不需建置，Vercel 直接部署。
- 資料存在瀏覽器 localStorage，請定期在 ⚙︎ 匯出 JSON 備份。
- 本工具僅供個人研究紀錄，不構成投資建議。
